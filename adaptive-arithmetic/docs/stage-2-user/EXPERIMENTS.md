# Stage 2 — Experiment Records and Guardrails

Status: Stage 2 planning opened 2026-10-23 (D-023); no experiment has started. No concrete study, assignment procedure, analysis, or result is approved. This is a lightweight record template for user-owned investigations. Read with the [research brief](RESEARCH_BRIEF.md).

## Evaluation guardrails

- Treat observed associations as hypotheses, not proof of causation. Consider difficulty, typing demands, session position, fatigue, practice, and chance as alternative explanations for sequential effects.
- Distinguish prediction accuracy, pattern verification, and learning benefit. Preserve independent fixed-distribution assessment instead of judging success only on adaptively selected training questions.
- Distinguish data used for discovery from evidence used for confirmation. Repeated testing and adaptive selection need explicit consideration; historical logs may be insufficient for valid retrospective comparisons.
- Use a nonadaptive baseline, transparent uncertainty, and modest initial hypotheses. Do not preselect a model family or treat sophistication as evidence.
- The user's own sessions may support debugging and individual investigations. They do not by themselves establish benefit for other users. Do not invent users, effect sizes, findings, or portfolio claims.

These principles do not constitute a completed methodology. Concrete comparisons and analysis choices remain for later discussion using the actual platform and [data contract](../stage-1-ai/DATA_CONTRACT.md).

## Template for a future experiment record

Copy this structure only when an investigation is agreed. No experiment has been created or run.

| Record item | Information to supply later |
| --- | --- |
| Identifier and status | Agreed identifier, owner, and proposed/approved/running/completed status. |
| Question | The precise question and whether it concerns prediction, pattern verification, or training benefit. |
| Hypothesis | A modest, explicit hypothesis and plausible alternative explanations. |
| Comparison | Conditions or baseline to compare, with what is held comparable. |
| Assignment procedure | How conditions/questions are assigned and what controls are possible; do not imply randomization if absent. |
| Outcome | The defined outcome, its timing/denominator, and how it relates to the stated objective. |
| Data requirements | Required observations/provenance, available coverage, missingness, unfinished work, and privacy limits. |
| Analysis plan | The plan agreed before analysis, including uncertainty, discovery/confirmation separation, repeated testing, and adaptive selection where relevant. |
| Limitations | Confounding, measurement limits, selection effects, population/scope limits, and what the study cannot establish. |
| Result | Actual procedure and evidence, deviations from plan, uncertainty, and supported interpretation; leave unreported until run. |
